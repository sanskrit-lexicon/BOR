# Front matter — Borooah, *English-Sanskrit Dictionary*

OCR (faithful Markdown) of the **front matter** of Anundoram Borooah's *English-Sanskrit Dictionary* (first published in three volumes 1877–1880; this edition reprinted by the **Publication Board, Assam**, Gauhati, 1971), plus a Russian translation of each page and consolidated single-file editions.

- **Dictionary:** *English-Sanskrit Dictionary* by **Anundoram Borooah** (1850–1889), B.A., I.C.S., Barrister-at-Law.
- **Source scans:** Cologne Digital Sanskrit Dictionaries — front-matter index [borpref.html](https://sanskrit-lexicon.uni-koeln.de/scans/csldev/csldoc/build/dictionaries/prefaces/borpref.html); page images under [`_images/`](https://sanskrit-lexicon.uni-koeln.de/scans/csldev/csldoc/build/_images/).
- **Source language:** English (with Sanskrit in Devanāgarī and IAST). Because the source is English, there is **no `.en.md`** — the base `borprefNN.md` is already English; a `.ru.md` Russian translation is provided for every page.

## File conventions

| Suffix | Meaning |
|---|---|
| `borprefNN.md` | Faithful OCR of page NN, English source (with Devanāgarī/IAST verbatim) |
| `borprefNN.ru.md` | Russian translation of page NN |
| `borpref_all.en.md` | All pages in order (English source) + table of contents |
| `borpref_all.ru.md` | All pages in order (Russian) + table of contents |
| `build_combined.py` | Reproducible builder of the `*_all.*` files (reads each page's YAML) |
| `MANIFEST.tsv` | Page → section label → volume → scan filename → sub-page URL |
| `scans/` | The 36 source page PNGs |

Rebuild the consolidated editions with `DICT=bor python build_combined.py`.

## Contents

The front matter falls in two parts: the **1971 reprint front matter** (publisher pages, V. Raghavan's Foreword, the Publication Board's Introduction, Borooah's own two Prefaces, the abbreviation lists, a portrait and a Sanskrit benediction), and three **Appendices** drawn from the back of the volume (biography, appreciations and obituaries of Borooah, printed pages 773–783).

## Notes

- **Source language is English**, so no `.en.md` files exist; the base `.md` is the English source. Russian (`.ru.md`) is provided for every page.
- **Signatures / dates found:** Preface to First Volume — *Burdwan, May 9th, 1877, A.B.*; Preface to Second Volume — *Goalpara, Oct. 27, 1878, A.B.*; Foreword — *V. Raghavan, Madras, 10-2-71*; Introduction — *Chandra Prasad Saikia, Secretary, Publication Board, Assam, Gauhati-3, July 1, 1971*.
- **Scan filenames jump** at page 26: the appendix scans are `bor_Page_798`…`bor_Page_808` (printed book pages 773–783), not the `…_026`-style numbering of the earlier pages. The MANIFEST records the true filenames.
- **Page 25** carries two Sanskrit sections — the *maṅgalācaraṇam* (benediction) and *granthavisarjanam* (dedication verses); the Devanāgarī is reproduced verbatim and **not translated** in the `.ru.md`.
- **Digitizer/library stamps** (e.g. the round *Universität zu Köln · Institut für Indologie* seal on some scans, and running header/footer credits) are **omitted** — they are not part of the original.
- Printed page numbers are preserved in brackets, e.g. `[xiv]`, `[774]`.
- Dense Sanskrit footnote conjuncts that could not be read with confidence are marked `[?]`; source typos (e.g. "conjuction", "ideclinable", "Mimānsā") are preserved as printed.
